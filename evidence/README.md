# Execution evidence

One folder per run under `runs/<UTC timestamp>-<slug>/` with:
- `manifest.json` — run id, timestamps, code version (git commit or content hash), command, environment, configuration, model identifiers, mocks used, expected vs actual, exit code, per-case outcomes
- `pytest.log`, `junit.xml` — raw output
- optional `summary.md`

Rules: never edit a past run; never store images, tokens, personal data or chain-of-thought; mark mocks.
Generated by `backend/scripts/record_evidence.py`. Runs before a git repository existed record `code_version.git = "uncommitted"` plus a content hash.
